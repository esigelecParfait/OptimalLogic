# Brief médias

Deux animations utilisent uniquement des interfaces HTML/CSS/SVG. La séquence
Présence digitale utilise un petit ensemble de photographies réelles afin
d’éviter l’apparence artificielle des images générées.

## Présence digitale

- 3 à 5 photographies documentaires de secteurs différents ;
- personnes, lieux ou gestes de travail crédibles, sans mise en scène publicitaire
  excessive ;
- droits commerciaux vérifiés, fichiers hébergés par OptimalLogic ;
- masters suffisamment grands pour les recadrages bureau et mobile ;
- point focal, crédit, licence, destination et texte alternatif consignés dans
  le registre d’actifs ;
- aucune photographie exclusivement décorative.

Le prototype peut utiliser des références temporaires, mais aucune URL distante
ou image sans droits ne doit atteindre la production.
