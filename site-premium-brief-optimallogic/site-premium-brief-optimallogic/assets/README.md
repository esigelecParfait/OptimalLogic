# Assets — OptimalLogic

Ce dossier contient des consignes et des mockups visuels pour guider la création du site premium OptimalLogic.

## Règle images

Les images utilisées dans le site doivent être :
- premium ;
- sobres ;
- en langue française ;
- cohérentes avec les couleurs OptimalLogic ;
- compréhensibles par des commerces locaux, indépendants, TPE/PME et startups.

  Direction visuelle pour un site web premium en français.

  Direction visuelle pour une fiche Google Business francophone.

- `reference-dashboard-acquisition.svg`
