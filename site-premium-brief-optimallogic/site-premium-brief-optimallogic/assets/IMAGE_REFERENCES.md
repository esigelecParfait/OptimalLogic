# Références images — OptimalLogic

Objectif : guider la direction visuelle du site premium OptimalLogic avec des références sobres, premium et en français.

Les références suivantes servent d’inspiration. Ne pas copier directement les visuels sans vérifier les droits.

## 1. Site web premium français — agence / communication digitale

### Référence : Nova Studio Conseil — mockup de site d’agence

À retenir :
- fond clair et chaleureux ;
- navigation française simple ;
- hero sobre ;
- CTA visible ;
- cartes de services propres ;
- style premium accessible aux petites entreprises.

Utilisation dans OptimalLogic : inspiration pour la structure du hero et des cartes services.

## 2. Site web français — création de site vitrine

### Référence : DIGITALISIM — page “création de site vitrine”

À retenir :
- texte français très clair ;
- promesse directe ;
- CTA projet ;
- mockup site web ;
- lisibilité forte.

Utilisation dans OptimalLogic : inspiration pour la page Services et les blocs “site web professionnel”.

## 3. Landing page agence digitale sombre

### Référence : Uniflow / agence digitale sombre

À retenir :
- contraste premium ;
- hero sombre ;
- CTA visibles ;
- perception moderne.

Utilisation dans OptimalLogic : uniquement pour les blocs sombres, le dashboard ou certains CTA. Ne pas transformer tout le site en full dark.

## 4. Fiche Google Business française — artisan

### Référence : fiche Google Business d’artisan présentée par Simplebo

À retenir :
- interface mobile ;
- note étoilée ;
- avis ;
- boutons “Itinéraire”, “Démarrer”, “Appeler” ;
- photos ;
- onglets “Aperçu”, “Services”, “Avis”, “Photos”, “Actualités”.

Utilisation dans OptimalLogic : inspiration principale pour le visuel de fiche Google Business dans le hero et les sections Google Business.

## 5. Fiche Google Business française — boutique parisienne

### Référence : fiche Google Business présentée par Geolid

À retenir :
- fiche claire ;
- horaires ;
- adresse ;
- téléphone ;
- site web ;
- note et avis.

Utilisation dans OptimalLogic : inspiration pour montrer la confiance locale et le passage vers le site / l’appel.

## Direction finale à produire

Créer ou intégrer des images qui montrent :

1. Une fiche Google Business française optimisée.
2. Un site web premium français sur desktop et mobile.
3. Un dashboard OptimalLogic avec demandes, RDV, prospects chauds et actions recommandées.
4. Un parcours simple : Google → fiche → appel / RDV → suivi prospect.

## Textes visibles dans les images

Tous les textes dans les images doivent être en français.

Exemples :
- Accueil
- Services
- Tarifs
- Contact
- Prendre RDV
- Appeler
- Itinéraire
- Réserver
- Avis
- Photos
- Horaires
- Demandes reçues
- RDV générés
- Prospects chauds
- Actions recommandées

## Style visuel des images

- fond crème ou blanc cassé ;
- texte noir ;
- boutons noirs ou champagne ;
- bords arrondis ;
- ombres douces ;
- interface propre ;
- pas de surcharge graphique ;
- pas d’anglais.
