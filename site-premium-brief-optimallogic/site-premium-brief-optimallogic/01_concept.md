# 01 — Concept & Vision

## Type de projet

Site web premium pour **OptimalLogic**, agence digitale orientée acquisition client.

Le site n’est pas seulement un site vitrine. Il doit fonctionner comme une porte d’entrée commerciale : il explique clairement le problème, rassure, montre les leviers disponibles, puis pousse le visiteur vers une action simple : réserver un diagnostic gratuit, demander une formule ou contacter OptimalLogic.

## Secteur d’activité

Digital, IA, acquisition client, visibilité locale, site web professionnel, Google Business, prise de rendez-vous, formulaires intelligents et suivi prospects.

## Positionnement

OptimalLogic aide les commerces locaux, indépendants, TPE/PME et startups à transformer leur présence en ligne en moteur de clients.

Le positionnement doit rester simple :

> Nous ne vendons pas des outils compliqués. Nous construisons le dispositif digital réellement utile à l’activité du client pour l’aider à être trouvé, compris, choisi et contacté plus facilement.

## Ambiance générale

Mots-clés :
- premium ;
- sobre ;
- clair ;
- intelligent ;
- rassurant ;
- stratégique ;
- orienté conversion.

L’ambiance doit être plus haut de gamme que “agence web classique”, sans devenir froide ou trop technologique. Il faut garder une sensation de proximité avec les commerces et petites entreprises.

## Public cible

### Cible principale
- commerces locaux ;
- restaurants ;
- salons / instituts ;
- artisans ;
- cabinets professionnels ;
- indépendants ;
- TPE/PME ;
- startups en validation ou lancement.

### Niveau de maturité digitale
Le visiteur peut ne pas savoir exactement ce dont il a besoin. Il peut penser qu’il lui faut “un site”, alors que son vrai problème peut être :
- une fiche Google incomplète ;
- peu d’avis ;
- des photos faibles ;
- pas de bouton de prise de rendez-vous ;
- un site peu clair ;
- des demandes prospects mal suivies ;
- une absence de relance commerciale.

## Objectif principal du site

Générer des demandes qualifiées et des rendez-vous de diagnostic gratuit.

Les objectifs secondaires :
- faire comprendre rapidement la valeur d’OptimalLogic ;
- montrer que chaque solution dépend du contexte du client ;
- rassurer sur la simplicité du parcours ;
- mettre en avant le lien entre visibilité, confiance, contact et suivi commercial ;
- préparer le visiteur à choisir une offre ou à demander conseil.

## Émotion recherchée après la visite

Le visiteur doit se dire :

> “Ils ont compris mon problème. Ce n’est pas juste un site web, c’est une solution pour recevoir plus de demandes et mieux gérer mes prospects.”

La sensation recherchée : confiance, clarté, sérieux, simplicité, envie de passer à l’action.

## Références et inspirations

### Références de sites web premium, sobres et francophones

À utiliser comme inspiration, pas à copier directement :

1. **Site agence digitale sobre avec hero clair, texte français et cartes services**  
   Inspiration : structure éditoriale, CTA visible, usage d’un fond clair, hiérarchie simple, cartes de services propres.

2. **Page de création de site vitrine en français**  
   Inspiration : phrase d’accroche très claire, promesse directe, bouton de contact visible, illustration de mockup site.

3. **Landing page d’agence digitale sombre et premium**  
   Inspiration uniquement pour les blocs sombres, le dashboard ou les zones de contraste. Ne pas transformer tout OptimalLogic en site full dark.

### Références Google Business

À intégrer dans l’univers visuel du site :
- fiche Google Business sur mobile ;
- avis clients ;
- note étoilée ;
- boutons “Appeler”, “Itinéraire”, “Réserver” ;
- photos d’établissement ;
- horaires ;
- lien vers le site web ;
- onglets “Aperçu”, “Services”, “Avis”, “Photos”.

### Ce qu’il faut retenir pour OptimalLogic

Le site doit montrer visuellement le passage suivant :

1. Le client est trouvé sur Google.
2. Il voit une fiche claire et rassurante.
3. Il clique, appelle ou réserve.
4. La demande arrive dans un système de suivi.
5. L’entreprise relance mieux et transforme plus facilement.

## À éviter

- Style trop flashy.
- Dégradés agressifs.
- Images génériques de start-up américaines.
- Interface en anglais.
- Trop d’effets 3D inutiles.
- Trop de promesses vagues du type “boostez votre business” sans preuve visuelle.
- Changer la navigation, le header ou le footer.
