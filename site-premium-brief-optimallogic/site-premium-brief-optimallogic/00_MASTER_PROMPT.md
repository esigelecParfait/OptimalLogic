# PROMPT FINAL — OptimalLogic

Crée-moi une version premium, sobre et professionnelle du site **OptimalLogic**, en gardant la structure commerciale actuelle et sans changer la navigation, le header ni le footer.

## Règle obligatoire

Ne modifie pas la navigation, le header et le footer.

À conserver :
- Logo : **OL Optimal Logic**
- Navigation : **Services**, **Tarifs**, **Contact**
- Accès : **Espace client**
- CTA header : **Prendre RDV**
- Footer : **OL Optimal Logic**, **Digital, IA & acquisition client**, **Mentions légales**, **Confidentialité**, **Cookies**

## Concept

OptimalLogic est une agence digitale orientée acquisition client.

Le site doit expliquer qu’OptimalLogic aide les commerces locaux, indépendants, TPE/PME et startups à transformer leur présence en ligne en moteur de clients grâce à :
- Google Business ;
- site web professionnel ;
- prise de rendez-vous ;
- assistant IA ;
- formulaire intelligent ;
- suivi des demandes prospects.

La promesse centrale :

> Faites de votre présence en ligne un vrai moteur de clients.

Sous-promesse :

> Google Business, site web, prise de rendez-vous, assistant IA et suivi des demandes — adaptés à votre activité.

## Positionnement

Ne pas présenter OptimalLogic comme une simple agence qui “fait des sites”.

Le message doit être :

> Nous partons de l’activité du client, puis nous activons uniquement les bons leviers digitaux pour l’aider à être trouvé, compris, choisi et contacté plus facilement.

## Ambiance visuelle

Ambiance : premium, sobre, claire, intelligente, rassurante, orientée conversion.

Le rendu doit être haut de gamme, mais accessible à un commerce local. Il ne doit pas ressembler à un site SaaS trop abstrait ou à une agence web trop flashy.

## Couleurs

Garde les couleurs actuelles du site OptimalLogic.

Palette à respecter :
- fond principal crème clair : `#F7F4EF` ;
- texte principal noir profond : `#050505` ;
- surfaces claires : `#FFFFFF` ou `#FCFAF6` ;
- texte secondaire gris chaud : `#6F6A60` ;
- bordures fines : `rgba(5, 5, 5, 0.08)` à `rgba(5, 5, 5, 0.14)` ;
- surface sombre ponctuelle : `#050505` ;
- texte sur fond sombre : `#FFFFFF` et `#B5B5BD` ;
- accent champagne très discret : `#D8C3A5` ou `#B8894B` uniquement pour les détails.

Ne pas utiliser de violet flashy, de bleu SaaS générique ou de dégradés agressifs.

## Typographie

Utilise une typographie sans-serif premium et très lisible : Inter, Geist, Manrope, Satoshi ou équivalent.

Les titres doivent être courts, impactants, avec une hiérarchie forte et beaucoup d’espace.

## Structure Accueil

Sections dans l’ordre :

1. **Hero**  
   Badge : Google Business • Site web • RDV • Assistant IA  
   Titre : Faites de votre présence en ligne un vrai moteur de clients.  
   Sous-titre : Google Business, site web, prise de rendez-vous, assistant IA et suivi des demandes — adaptés à votre activité.  
   CTA : Réserver un appel gratuit / Améliorer ma visibilité  
   Visuel : composition premium avec fiche Google Business mobile, mini site web et dashboard prospects OptimalLogic.

2. **Bandeau leviers**  
   Google Business · Site web professionnel · Prise de RDV · Assistant IA · Formulaire intelligent · Suivi prospects.

3. **Pour qui ?**  
   Commerce local, indépendant, PME ou startup.

4. **Le vrai problème**  
   Fiche Google incomplète, site peu convaincant, demandes mal traitées, parcours de contact flou.

5. **Notre vision**  
   Nous ne partons pas d’un outil. Nous partons de votre activité.

6. **Solutions**  
   Assistant IA, site web professionnel, prise de RDV, Google Business, suivi prospects.

7. **Notre différence**  
   On part de votre activité, on active les bons leviers, on évite la complexité inutile, on mesure ce qui compte.

8. **Résultats**  
   Être mieux trouvé, inspirer confiance, recevoir plus de demandes, gagner du temps.

9. **Activités accompagnées**  
   Commerces locaux, restaurants, salons, artisans, cabinets, PME, startups, formateurs, prestataires.

10. **CTA final**  
   Vous ne savez pas par où commencer ? C’est justement notre rôle.  
   CTA : Réserver un appel gratuit / Nos formules.

## Direction images

Les images doivent être premium, sobres et en français.

Utiliser :
- mockups de sites web français haut de gamme ;
- fiches Google Business en français ;
- boutons “Appeler”, “Itinéraire”, “Réserver” ;
- avis clients ;
- photos d’établissement ;
- dashboards prospects ;
- mockups desktop + mobile.

Éviter :
- interfaces en anglais ;
- images corporate génériques ;
- captures trop colorées ;
- visuels SaaS abstraits.

Des références et mockups sont disponibles dans le dossier `assets` du brief.

## Animations

Animations premium sobres :
- apparition douce au chargement ;
- fade + translateY au scroll ;
- cartes avec hover subtil ;
- mockup téléphone en légère perspective ;
- dashboard avec micro-parallax ;
- chiffres qui se révèlent doucement ;
- pas de 3D lourde ;
- respecter `prefers-reduced-motion`.

## Contraintes techniques

- Next.js
- React
- Tailwind CSS
- Compatible Vercel
- Responsive parfait mobile / tablette / desktop
- Performance prioritaire
- Ne pas casser les formulaires, la prise de RDV, l’espace client ou les pages légales

## Ton éditorial

Français clair, court, direct, rassurant.

Le visiteur doit comprendre rapidement :
1. le problème ;
2. ce qu’OptimalLogic fait ;
3. pourquoi c’est utile ;
4. quelle action faire maintenant.

Construis d’abord la structure et l’ambiance générale. Les animations et détails visuels pourront être affinés ensuite section par section.
