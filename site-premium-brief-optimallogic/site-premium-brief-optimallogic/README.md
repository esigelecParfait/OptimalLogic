# Kit de brief — Site Premium OptimalLogic

Ce dossier est une version adaptée du kit `site-premium-brief` pour le projet **OptimalLogic**.

Objectif : préparer une refonte ou une amélioration visuelle premium du site **optimal-logic.com**, tout en gardant la structure commerciale existante.

## Règle principale

Ne pas modifier la navigation, le header et le footer actuels.

Le site doit conserver :
- le logo / identité **OL Optimal Logic** ;
- la navigation principale : **Services**, **Tarifs**, **Contact** ;
- les accès : **Espace client** et **Prendre RDV** ;
- le footer avec **Optimal Logic**, la phrase **Digital, IA & acquisition client**, et les liens légaux : **Mentions légales**, **Confidentialité**, **Cookies**.

## Ce que ce brief cherche à améliorer

Le site actuel est déjà cohérent dans le fond : il explique qu’OptimalLogic aide les commerces, indépendants, TPE/PME et startups à transformer leur présence en ligne en demandes concrètes.

La version premium doit surtout renforcer :
- la perception haut de gamme ;
- la clarté du parcours ;
- la preuve visuelle autour de Google Business, site web, prise de rendez-vous, assistant IA et suivi prospects ;
- la confiance immédiate ;
- l’envie de réserver un diagnostic gratuit.

- `05_technique.md` — contraintes techniques.
- `06_contenu.md` — textes réels à intégrer.

- `assets/IMAGE_REFERENCES.md` — références visuelles à utiliser comme inspiration.
- `assets/*.svg` — mockups visuels sobres en français, créés pour le brief.

## Note importante sur les images

Les références trouvées sur le web servent à définir une direction artistique. Elles ne doivent pas être copiées telles quelles dans le site final sans vérifier les droits d’utilisation.

Pour le site final, il faut privilégier :
- des captures réelles produites par OptimalLogic ;
- des mockups créés sur mesure ;
- des images libres de droits ;
- des visuels en français, sobres, premium et crédibles.
