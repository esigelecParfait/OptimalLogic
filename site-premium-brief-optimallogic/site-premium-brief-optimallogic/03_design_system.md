# 03 — Design System

## Principe général

Garder les couleurs actuelles d’OptimalLogic. La refonte doit améliorer la perception premium sans changer l’identité.

Le site doit rester :
- clair ;
- sobre ;
- professionnel ;
- lisible ;
- chaleureux ;
- orienté business local et acquisition client.

## Palette de couleurs à conserver

Palette recommandée, alignée avec l’identité actuelle :

- Fond principal : `#F7F4EF`  
  Crème clair, chaleureux, premium, déjà cohérent avec l’univers OptimalLogic.

- Texte principal : `#050505`  
  Noir profond, sérieux, lisible.

- Texte secondaire : `#6F6A60`  
  Gris chaud / brun doux pour les paragraphes et textes d’accompagnement.

- Surfaces claires : `#FFFFFF` ou `#FCFAF6`  
  Cartes, blocs de contenu, formulaires.

- Bordures : `rgba(5, 5, 5, 0.08)` à `rgba(5, 5, 5, 0.14)`  
  Bordures fines, discrètes, premium.

- Surface sombre ponctuelle : `#050505`  
  À utiliser pour les dashboards, CTA forts, badges importants ou zones de contraste.

- Texte sur fond sombre : `#FFFFFF` et `#B5B5BD`  
  Blanc et gris clair pour les panneaux sombres.

- Accent chaud très discret : `#D8C3A5` ou `#B8894B`  
  À utiliser très légèrement : pastilles, icônes, détails premium, micro séparateurs. Ne pas en faire une couleur dominante.

## À ne pas faire avec les couleurs

- Ne pas passer sur une palette bleue SaaS générique.
- Ne pas utiliser de violet flashy.
- Ne pas utiliser de dégradés très colorés.
- Ne pas transformer le site en full dark.
- Ne pas changer le noir/crème qui constitue déjà la base visuelle.

## Typographie

### Titres
Style : sans-serif premium, géométrique ou éditoriale, avec beaucoup d’espace.

Exemples possibles :
- Inter
- Geist
- Satoshi
- Manrope
- Neue Haas Grotesk si disponible

Traitement :
- gros titres courts ;
- interlignage serré mais lisible ;
- poids 600 à 800 ;
- tracking légèrement négatif sur les grands titres.

### Texte courant
Style : très lisible, sobre, professionnel.

Traitement :
- taille confortable ;
- largeur de ligne limitée ;
- couleur secondaire chaude ;
- phrases courtes.

## Style visuel général

À privilégier :
- design éditorial premium ;
- cartes claires avec bordures fines ;
- grands espaces blancs / crème ;
- hiérarchie forte ;
- éléments visuels de type dashboard ;
- mockups mobile pour Google Business ;
- badges sobres ;
- CTA noirs ou très foncés ;
- micro-accents champagne.

Cases stylistiques :
- [x] Luxe / éditorial sobre
- [x] Flat design premium
- [x] Dashboard SaaS minimal
- [x] Glassmorphism très léger uniquement sur le header ou certaines cartes
- [ ] Brutalisme
- [ ] Effets néon
- [ ] 3D spectaculaire

## Imagerie

Les images doivent être :
- premium ;
- sobres ;
- en langue française ;
- crédibles pour commerces, indépendants, TPE/PME et startups ;
- cohérentes avec les couleurs du site.

### Types d’images à utiliser

1. **Mockups de sites web premium français**
   - desktop + mobile ;
   - navigation française ;
   - CTA français ;
   - hero clair ;
   - cartes services ;
   - sections témoignages / résultats.

2. **Mockups de fiche Google Business en français**
   - note étoilée ;
   - avis ;
   - photos ;
   - horaires ;
   - boutons “Appeler”, “Itinéraire”, “Réserver” ;
   - onglets “Aperçu”, “Services”, “Avis”, “Photos”.

3. **Mockups de dashboard OptimalLogic**
   - demandes reçues ;
   - RDV générés ;
   - prospects chauds ;
   - valeur estimée ;
   - actions recommandées.

4. **Images métier sobres**
   - commerçant en boutique ;
   - restaurant / salon / cabinet ;
   - artisan ;
   - ordinateur avec tableau de bord ;
   - smartphone affichant une fiche locale.

## Images à éviter

- Photos corporate trop génériques.
- Images américaines avec textes anglais.
- Captures non francophones.
- Visuels très colorés qui cassent la palette.
- Mockups trop futuristes qui donnent l’impression d’un produit inaccessible.
