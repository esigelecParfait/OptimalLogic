# 02 — Structure & Navigation

## Type de navigation

Site multi-pages classique, avec un header fixe ou semi-fixe, sobre et premium.

### Navigation à conserver impérativement

Ne pas changer la navigation actuelle :

- Logo : **OL Optimal Logic**
- Liens principaux : **Services**, **Tarifs**, **Contact**
- Accès secondaire : **Espace client**
- CTA principal : **Prendre RDV**

Le header peut être amélioré visuellement de manière subtile : transparence légère, bordure fine, effet de flou au scroll, meilleure lisibilité mobile. Mais il ne faut pas ajouter, supprimer ou renommer les liens.

## Pages à conserver

- Accueil
- Services
- Tarifs
- Contact
- Prise de RDV
- Espace client
- Pages légales : Mentions légales, Confidentialité, Cookies

## Structure page Services

Objectif : expliquer les services sans créer de confusion.

Sections recommandées :
1. Hero Services : “Les bons leviers digitaux, selon votre activité.”
2. Google Business : visibilité locale, avis, photos, horaires, appels, itinéraires.
3. Site web professionnel : clarté, crédibilité, conversion, mobile.
4. Prise de rendez-vous : simplifier le passage à l’action.
5. Assistant IA : répondre aux questions fréquentes et guider le visiteur.
6. Formulaire intelligent : qualifier les demandes.
7. Suivi prospects : centraliser les demandes et relances.
8. CTA : diagnostic gratuit.

## Structure page Tarifs

Objectif : rendre les offres lisibles et rassurantes.

Ne pas transformer la page en catalogue trop chargé. Les formules doivent rester claires par cible :

### Commerce
- Commerce Intelligent
- Commerce Premium

### TPE/PME
- Présence Pro
- Croissance
- Performance

### Startup
- Validation
- Launch
- Growth

Chaque offre doit afficher :
- cible ;
- promesse ;
- prix ;
- ce qui est inclus ;
- mensualité si applicable ;
- CTA : demander cette formule ou prendre RDV.

## Structure page Contact

Objectif : permettre une demande simple, sans friction.

Le formulaire doit rester utile mais pas lourd. Les champs doivent être regroupés visuellement :
1. Identité
2. Activité
3. Besoin
4. Message
5. Consentement RGPD

## Structure page Prise de RDV

Objectif : rassurer avant la réservation.

Ajouter autour du module de réservation :
- rappel “Diagnostic gratuit, sans engagement” ;
- ce qui se passe pendant l’appel ;
- durée courte ;
- promesse : repartir avec une recommandation claire.

## Footer

Footer à conserver dans son contenu :

- OL Optimal Logic
- Digital, IA & acquisition client.
- Mentions légales
- Confidentialité
- Cookies

Le footer peut être rendu plus premium avec :
- plus d’espace ;
- typographie plus propre ;
- contraste doux ;
- bordure supérieure fine ;
- organisation plus lisible.

Mais ne pas ajouter une navigation compliquée ni répéter trop de liens.
